# منصوركو بوت (Kick Mod Bot)

بوت لقناتك على كيك بيمسح من الشات أي رسالة فيها شتيمة أو اسم من الأسماء اللي انت محددها. بيمسك الكلمة حتى لو اتكتبت متلخبطة:

- حروف متكررة: `حمااار`
- مسافات بين الحروف: `ح م ا ر`
- تشكيل
- فرانكو
- كلمة لازق فيها حرف أو أداة: `والحمار` و`ياحمار`

ليه لوحة تحكم بالعربي تضيف وتشيل منها الكلمات والأسماء، وتشوف فيها كل رسالة اتمسحت.

- رسايلك انت عمرها ما بتتمسح.
- رسايل المودز مش بتتمسح، وده إعداد تقدر تقفله من اللوحة.
- البوت بيمسح الرسالة بس، ومش بيعمل تايم أوت أو باند.

## الرفع على Railway خطوة بخطوة

### 1. اعمل App على كيك

1. فعّل التحقق بخطوتين (2FA) على حسابك في كيك. من غيره صفحة المطورين مش هتفتح.
2. ادخل على `https://kick.com/settings/developer` واعمل App جديد.
3. انسخ الـ **Client ID** والـ **Client Secret** واحفظهم. هتحتاجهم في الخطوة 3.
4. سيب خانة الـ Redirect URL وخانة الـ Webhook دلوقتي. هنرجعلهم بعد ما يبقى معانا رابط Railway.

### 2. ارفع الكود على Railway

1. ارفع فولدر المشروع على GitHub في repo خاص (private).
2. على [railway.com](https://railway.com) اختار **New Project**، وبعدها **Deploy from GitHub repo**، وبعدها اختار الـ repo.
3. Railway هيلاقي الـ `Dockerfile` ويبني منه لوحده.
4. افتح الـ service، وبعدها **Settings** ثم **Networking** ثم **Generate Domain**. هيدّيك رابط شكله كده: `https://kick-mod-bot-production.up.railway.app`. ده الـ `PUBLIC_URL` بتاعك.
5. اعمل كليك يمين على الـ service واختار **Attach Volume**. خلي الـ Mount path يبقى `/data`. هنا قاعدة البيانات بتتحفظ، ومن غيره القوايم والسجل هيتمسحوا مع كل تحديث.

### 3. حط الإعدادات (Variables)

من تاب **Variables** في الـ service، ضيف المتغيرات دي:

| المتغير | القيمة |
|---|---|
| `KICK_CLIENT_ID` | من صفحة المطورين على كيك |
| `KICK_CLIENT_SECRET` | من صفحة المطورين على كيك |
| `PUBLIC_URL` | رابط Railway من خطوة 2، من غير `/` في الآخر |
| `OWNER_KICK_USERNAME` | يوزر كيك بتاعك انت، زي ما هو في رابط قناتك. الحساب ده بس هو اللي متحكم في كل حاجة |
| `SESSION_SECRET` | نص عشوائي طوله 32 حرف أو أكتر. تقدر تطلّعه بالأمر اللي تحت |
| `GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET` و`OWNER_EMAIL` | اختياري: الدخول الاحتياطي بجوجل. الخطوات تحت في «الدخول الاحتياطي بجوجل». حطهم التلاتة أو ولا واحد |

الأمر ده بيطلّعلك `SESSION_SECRET`:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

متغيرات `DATA_DIR` و`PORT` مش محتاجهم. البوت بيستخدم `/data` لوحده، وRailway بيحط الـ `PORT` لوحده.

### 4. ارجع لكيك وكمّل الربط

ادخل على الـ App بتاعك في صفحة المطورين وحط القيم دي:

- **Redirect URL:** `PUBLIC_URL/auth/kick/callback`، يعني مثلًا `https://kick-mod-bot-production.up.railway.app/auth/kick/callback`
- **Enable Webhooks:** خليها On
- **Webhook URL:** `PUBLIC_URL/webhook`

### 5. ادخل واربط حساب البوت

1. افتح الـ `PUBLIC_URL` في المتصفح ودوس **«ادخل بحساب كيك»**. البوت هيعرف إنك صاحب القناة من `OWNER_KICK_USERNAME`.
2. روح صفحة **«الإعدادات»** ودوس **«اربط حساب البوت»**، ووافق على الصلاحيات. ده الحساب اللي هيمسح الرسايل.
3. في الرئيسية هتلاقي «حساب البوت: متصل» و«الاستقبال شغال».

### 6. جرّبه

- **في اللوحة:** من صفحة **«التجربة»** اكتب أي رسالة وشوف هتتمسح ولا لأ.
- **في الشات:** ادخل الشات **بحساب تاني**، لأن رسايلك انت مش بتتمسح، واكتب كلمة من القايمة. هتختفي، وهتلاقيها في صفحة **«السجل»**.

## الرفع على أي هوست تاني (VPS أو هوست بيدعم Node.js)

الملف المضغوط `kick-mod-bot-deploy.zip` فيه الكود مبني وجاهز. السيرفر واللوحة جاهزين في `server/dist` و`web/dist`.

**المطلوب من الهوست:**
- **Node.js 22 أو أحدث.**
- **رابط HTTPS عام**، عشان كيك يبعت الرسايل للبوت.
- **فولدر بيفضل محفوظ** وما بيتمسحش مع التحديثات. ده اللي هتحطه في `DATA_DIR`.
- **البوت لازم يفضل شغال على طول**، ومش بيتقفل لما مفيش زيارات.

**الخطوات:**

1. ارفع الملف المضغوط وفكّه.
2. حط المتغيرات اللي في جدول الخطوة 3 فوق في إعدادات الهوست. لو الهوست مفيهوش إعدادات متغيرات، اعمل ملف `.env` من `.env.example` جنب `package.json`.
3. حط كمان `DATA_DIR` بمسار الفولدر المحفوظ، و`PORT` لو الهوست بيطلب بورت معين.
4. ثبّت المكتبات على الهوست نفسه. الأمر ده بيستخدم نسخة SQLite الجاهزة لنظام الهوست، فمش محتاج أدوات بناء:

   ```bash
   npm ci --omit=dev --ignore-scripts
   ```

5. شغّل البوت:

   ```bash
   npm start
   ```

   لو بتستخدم ملف `.env`، شغّله بالأمر ده بدل اللي فوقه:

   ```bash
   node --env-file=.env server/dist/index.js
   ```

6. **على VPS:** خليه يشتغل على طول ويرجع لوحده لو وقع. مثلًا بـ pm2:

   ```bash
   npx pm2 start server/dist/index.js --name kick-mod-bot
   ```

7. كمّل من الخطوة 4 فوق: حط Redirect URL وWebhook URL في كيك برابط الهوست.

**لو الهوست بيدعم Docker:** الـ `Dockerfile` الموجود بيبني كل حاجة لوحده. اربط Volume على `/data`.

## حساب بوت منفصل (اختياري)

لو عايز المسح يظهر إنه اتعمل من حساب زي `MansourkoBot` مش من حسابك:

1. اعمل حساب كيك جديد.
2. خليه **مود** في قناتك.
3. في الخطوة 5، وانت بتدوس «اربط حساب البوت»، سجّل دخول في كيك بالحساب الجديد مش بحسابك.

## المودز والصلاحيات

كيك مفيهوش طريقة تجيب قايمة المودز بتوع قناتك، فانت بتضيفهم بنفسك من صفحة **«الفريق»**:

1. اكتب يوزر كيك بتاع المود، واختار الصلاحيات أو قالب جاهز:
   - **مراقب:** يشوف السجل بس
   - **محرر قوايم:** يعدّل القوايم ويشوف السجل
   - **مساعد كامل:** كل حاجة، ومنها تشغيل وإيقاف البوت
2. المود يدخل اللوحة بزرار «ادخل بحساب كيك». أول دخول ليه بيربط اليوزر بحسابه.
3. لو المود كتب في الشات وعنده علامة مود، هيظهرلك في «مودز شفناهم في الشات»، وتضيفه بضغطة.

**حاجات مهمة:**

- لو شلت حد من الفريق أو غيّرت صلاحياته، التغيير بيشتغل على طول، من غير ما يخرج ويدخل.
- إدارة الفريق، و«سجل التعديلات»، وربط حساب البوت، دول ليك انت بس.
- كل تعديل في القوايم أو الإعدادات أو الفريق بيتسجل في «سجل التعديلات» باسم وصورة اللي عمله.

## الدخول الاحتياطي بجوجل (اختياري)

لو كيك وقع أو تسجيل الدخول بيه فشل، تقدر تدخل كصاحب القناة بإيميلك على جوجل:

1. ادخل على [console.cloud.google.com](https://console.cloud.google.com) واعمل مشروع جديد.
2. من **APIs & Services** ادخل على **OAuth consent screen**:
   - اختار **External**
   - اكتب اسم التطبيق وإيميلك
   - ضيف نفسك في **Test users**
3. من **Credentials** اختار **Create credentials** ثم **OAuth client ID**:
   - النوع: **Web application**
   - في **Authorized redirect URIs** حط `PUBLIC_URL/auth/google/callback`
4. انسخ الـ **Client ID** والـ **Client Secret**، وحطهم في Railway كده:
   - `GOOGLE_CLIENT_ID`
   - `GOOGLE_CLIENT_SECRET`
   - `OWNER_EMAIL`: إيميلك على جوجل

بعد كده هيظهر زرار **«ادخل بجوجل»** في صفحة الدخول. الإيميل اللي في `OWNER_EMAIL` بس هو اللي يقدر يدخل بيه.

## القوايم

- **شتايم:** أي رسالة فيها كلمة من دول بتتمسح. البوت بيبدأ ومعاه قايمة جاهزة فيها حوالي 55 كلمة (مصري وفرانكو وإنجليزي)، وتقدر تعدّلها زي ما انت عايز.
- **أسماء:** أي رسالة فيها اسم من دول بتتمسح. ينفع تكتب اسم من كذا كلمة، زي `محمد منصور`، وساعتها الرسالة بتتمسح بس لو الكلمتين جم ورا بعض.
- **مسموح:** كلمات عادية جواها شتيمة بالصدفة. ضيفها هنا لو البوت مسح رسالة بالغلط. القايمة دي بتبدأ ومعاها `خولة` و`زبون` و`زبونة`.

**طريقة المسك:**

- **«الكلمة نفسها»:** الافتراضي، وده الأنسب في أغلب الحالات.
- **«جوه أي كلمة»:** للكلمات الطويلة بس، لأنها ممكن تمسح كلام عادي.

**الفرانكو:** ضيف الشكل الفرانكو كبند لوحده، زي `7mar`.

## لو حاجة مش شغالة

| اللي ظاهر | السبب والحل |
|---|---|
| «حساب البوت: محتاج ربط» | ربط حساب البوت انتهى أو اتلغى. ادخل كصاحب القناة، وروح «الإعدادات»، ودوس «اربط حساب البوت». |
| في السجل: «الحساب مش مود في القناة» | الحساب اللي ربطته مش مود في قناتك. خليه مود، أو اربط بحسابك انت. |
| «استقبال رسايل الشات: فيه مشكلة» | اتأكد إن الـ Webhook URL في كيك هو `PUBLIC_URL/webhook` بالظبط، وإن Enable Webhooks شغالة. |
| «آخر رسالة وصلت» مش بتتحدث | نفس اللي فوق. كمان كيك بيلغي الاشتراك لو البوت فضل واقف أكتر من يوم، بس البوت بيرجّعه لوحده كل 30 دقيقة. |
| القوايم بتتمسح بعد كل تحديث | الـ Volume مش متركب على `/data`. ارجع للخطوة 2. |

## التشغيل على جهازك (للتطوير)

1. ثبّت المكتبات:

   ```bash
   npm install
   ```

   لو على ويندوز وطلع خطأ `gyp ERR! find VS`، يبقى مكتبة SQLite بتحاول تتبني من الصفر. استخدم ده بدله، لأنها جاية بنسخة جاهزة:

   ```bash
   npm install --ignore-scripts
   ```

2. اعمل ملف `.env` من `.env.example`، وخلي فيه:
   - `PUBLIC_URL=http://localhost:3000`
   - `DATA_DIR=./data`

3. شغّل السيرفر واللوحة. اللوحة هتفتح على `http://localhost:5173`:

   ```bash
   npm run dev
   ```

4. كيك محتاج رابط عام عشان يبعت الرسايل، فاعمل tunnel:

   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```

   وحط الرابط اللي يطلع في `PUBLIC_URL` وفي إعدادات الـ App على كيك. عشان تربط حساب كيك وانت بتطوّر، افتح اللوحة من رابط الـ tunnel نفسه، مش من `localhost:5173`.

**ملحوظة:** زرار «خروج» بيخرجك من المتصفح اللي انت فاتح منه بس. لو حاسس إن حد تاني دخل اللوحة، غيّر `SESSION_SECRET` وأعد تشغيل البوت، وساعتها كل الجلسات المفتوحة هتقفل.

**أوامر تانية:**

- الاختبارات:

  ```bash
  npm test
  ```

- فحص الأنواع:

  ```bash
  npm run typecheck
  ```

- بناء نسخة الإنتاج:

  ```bash
  npm run build
  ```

- تشغيل نسخة الإنتاج:

  ```bash
  npm start
  ```
